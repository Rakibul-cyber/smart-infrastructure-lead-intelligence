Use these settings when preparing the public GitHub repository. Apply them
manually in GitHub after confirming that the repository contains no sensitive
data.

## Manual Setup Steps

1. Open the repository on GitHub.
2. Go to **Settings**.
3. In **General**, set the repository description exactly as shown above.
4. Leave the website field blank unless a public demo URL is available.
5. Enable or disable repository features to match this guide.
6. Return to the repository main page and click the settings gear beside
   **About**.
7. Add the recommended topics, then save the changes.
