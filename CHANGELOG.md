## [0.1.0] - 2026-07-30

### Added

- Static scraping with Requests and Beautiful Soup.
- Playwright dynamic rendering.
- Static, dynamic, and automatic scrape strategy.
- Controlled multi-page crawler.
- Retries, exponential backoff, and request pacing.
- Rule-based business signal detection.
- Transparent 0-100 lead scoring.
- Single-organisation CLI analysis.
- Batch CSV organisation processing.
- Partial-failure reporting.
- Excel export with:
  - All Leads
  - High Priority
  - Evidence
  - Run Summary
- Management dashboard.
- Environment and `.env` configuration.
- Structured console and optional file logging.
- Docker and Docker Compose support.
- Non-root runtime container.
- Docker smoke tests.
- GitHub Actions CI.
- Dependabot configuration.
- Fictional demonstration data.
- Automated test suite.
